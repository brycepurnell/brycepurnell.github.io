# Bryce Purnell's Cultural Landing Page

A personal landing page showcasing my curated collection of art, poetry, books, music, sports, and political works.

## Deployment

This site is deployed using GitHub Pages and can be accessed at: `https://[your-github-username].github.io/[repository-name]`

## Local Development

To run this site locally, simply open the `index.html` file in your web browser.

## Technologies Used

- HTML5
- Tailwind CSS
- Responsive Design
